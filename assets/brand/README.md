# Metralign identity

The mark depicts two coordinate frames resolving to one measured site. The light frame represents the finely sampled reference; the slate frame represents the wider-field search; the oxide center denotes the reported coordinate.

The vectors are hand-authored project artwork. No generative-image system was used to create the identity.

| Color | Value | Use |
|---|---|---|
| Instrument black | `#070a0e` | Primary field |
| Reference ivory | `#f2eee4` | Fine-sampling frame |
| Search slate | `#66727d` | Wider-field frame |
| Measurement oxide | `#d85b3f` | Resolved coordinate |

Use `metralign-mark.svg` on digital surfaces, `metralign-symbol.svg` when a container is supplied by the application, and `metralign-mark-mono.svg` when only one ink is available. Do not rotate the symbol, recolor individual frame segments, add effects, or use the former P-shaped mark.
