# Real-imagery attribution

The evaluation code in this directory follows the repository's software license. Source microscopy and raster plates derived from it retain the source datasets' attribution requirements under Creative Commons Attribution 4.0. The software license does not supersede those image licenses.

## Registered TEM material

Wieslander, Håkan; Wählby, Carolina; Sintorn, Ida-Maria. *Transmission Electron Microscopy Dataset for Image Deblurring*, version 1.0. Zenodo (2020). [DOI 10.5281/zenodo.4113244](https://doi.org/10.5281/zenodo.4113244). Licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Associated article: Wieslander, H.; Wählby, C.; Sintorn, I.-M. *TEM image restoration from fast image streams*. PLOS ONE 16(2): e0246336 (2021). [DOI 10.1371/journal.pone.0246336](https://doi.org/10.1371/journal.pone.0246336).

`results/registered-tem-measured-plate.png`, when present, contains resized/cropped pixels from the publisher Test split plus measured coordinate overlays. Its JSON sidecar binds the precise source members and evaluation report.

`results/real-microscopy-success-plate.png` contains resized/cropped pixels from the exact Carinthia archive members, Boiko TIFFs, and MiniTEM archive members plus measured coordinate overlays. Its JSON sidecar binds all six shown cases, both evaluation reports, and raw source hashes. The displayed crops, resizing, contrast windows, labels, and coordinate overlays are modifications made for this evaluation; the underlying microscopy remains under CC BY 4.0.
